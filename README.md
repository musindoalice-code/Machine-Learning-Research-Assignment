# Machine-Learning-Research-Assignment

# Machine Learning Research & Practical Data Preparation

### Understanding how machines learn from data

Machine learning is changing how organisations use data to solve problems, identify patterns and make better decisions. This project explores the fundamentals of machine learning, the different ways algorithms learn, and the importance of preparing quality data before building a model.

Through research and practical Python exercises, I explored how raw data can be transformed into information that machine learning algorithms can understand and learn from.

The project combines theoretical understanding with practical application using **Python, pandas, scikit-learn and Jupyter Notebook**.

---

## Project Overview

This project was completed as part of the BrightLearn Machine Learning Research Assignment (October–November 2026).

The objective was to develop an understanding of machine learning, investigate its practical applications and demonstrate the data preparation techniques required before training a machine learning model.

The assignment is organised into four main sections.

## What This Project Covers

### Part A: Introduction to Machine Learning
- Understanding machine learning and how it differs from traditional programming.
- Exploring the relationship between Artificial Intelligence, Machine Learning, Deep Learning and Data Science.
- Understanding datasets, features, labels, models, training and predictions.
- Exploring real-world applications of machine learning.
- Understanding the machine learning workflow.

### Part B: Supervised vs Unsupervised Learning
- Understanding supervised learning and labelled datasets.
- Exploring unsupervised learning and pattern discovery.
- Comparing classification and regression.
- Understanding clustering and dimensionality reduction.
- Exploring machine learning algorithms using scikit-learn.

### Part C: Data Preparation and Practical Implementation
This section focuses on preparing raw data for machine learning.

The practical work includes:
- Exploring datasets using pandas.
- Identifying missing values and duplicate records.
- Cleaning and handling missing data.
- Encoding categorical variables.
- Scaling numerical features.
- Identifying and handling outliers.
- Feature engineering.
- Splitting data into training and testing sets.

The practical implementation uses pandas and scikit-learn in a Jupyter Notebook.

### Part D: Further Machine Learning Research
This section explores additional machine learning concepts, including topics such as:

- Overfitting and underfitting.
- Model evaluation metrics.
- Cross-validation.
- Decision trees and random forests.
- K-means clustering.
- Class imbalance.
- Machine learning pipelines.
- Bias and fairness.
- Data protection and POPIA.
- Careers in machine learning.

## Why Data Preparation Matters

A machine learning model is only as reliable as the data used to train it.

Raw datasets often contain missing values, inconsistent formats, duplicate records and variables that cannot be directly interpreted by an algorithm.

This project highlights the importance of preparing data carefully before model development. It also explores why decisions such as choosing the correct encoding method, scaling numerical variables and preventing data leakage matter.
